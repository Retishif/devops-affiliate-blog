# About this site

Cloud Native Craft is a set of practical guides for engineers who build and run cloud infrastructure. I'm a software engineer working with cloud-native platforms and CI/CD, and I write about the problems that come up in that work.

The topics include:

- Infrastructure as Code with Terraform and OpenTofu
- CI/CD pipelines and deployment automation
- Containers and cloud-native platforms
- Observability, reliability, and day-two operations
- Cost and operational trade-offs between infrastructure providers

## Editorial principles

The goal is to help you make better engineering decisions. To that end:

1. **Trade-offs come first.** Every recommendation comes with its limitations and operational costs.
2. **Primary sources win.** Anything version-sensitive is checked against official product documentation.
3. **Assumptions are stated.** Examples may need adapting to your environment, permissions, and software versions.
4. **No unsupported guarantees.** A sample configuration isn't automatically secure, production-ready, or right for every workload.
5. **Commercial relationships are disclosed.** Affiliate links are identified, and the [Affiliate Disclosure](/affiliate-disclosure) explains how.

## Corrections and feedback

If you find an error, an outdated instruction, or something unclear, please [open an issue on GitHub](https://github.com/Retishif/devops-affiliate-blog/issues). Include the page URL, the section, and, if you can, the product version or documentation that supports the correction.
