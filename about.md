# About this site

Cloud Native & DevOps Architecture publishes practical technical notes and implementation guides for engineers who build and operate cloud infrastructure.

The topics include:

- Infrastructure as Code with Terraform and OpenTofu
- CI/CD pipelines and deployment automation
- Containers and cloud-native platforms
- Observability, reliability, and day-two operations
- Cost and operational trade-offs between infrastructure providers

## Editorial principles

Technical content should help readers make informed engineering decisions. To support that goal:

1. **Explain trade-offs.** Recommendations should include relevant limitations and operational costs.
2. **Prefer primary sources.** Version-sensitive behavior should be checked against official product documentation.
3. **Be clear about assumptions.** Examples may require adaptation for a reader's environment, permissions, and software versions.
4. **Avoid unsupported guarantees.** A sample configuration is not automatically secure, production-ready, or suitable for every workload.
5. **Disclose commercial relationships.** Affiliate links, when used, are identified in the [Affiliate Disclosure](/affiliate-disclosure).

## Corrections and feedback

If you find an error, outdated instruction, or unclear explanation, please open an issue in the [GitHub repository](https://github.com/Retishif/devops-affiliate-blog/issues). Include the page URL, the relevant section, and—where possible—the product version or documentation that supports the correction.
